Rates are private to finance and the owner. Each rate is a version that takes effect on a date; you never edit one.

## Add a rate version

On **Rates**, **Add rate version** sets the **Person** (or none, for a rate that applies to a service for everyone), the **Service** (**All services** covers every service that person records), the **Effective date**, the **Cost per hour** and the **Bill per hour** in dollars. Leave the cost blank when it is unknown.

## Approved work keeps its rate

When time is approved, Gauge fixes the rate that applied on the day the work was done. Adding a rate today never changes work approved earlier. To change a rate from a date, add a new version with that effective date; the earlier versions stay in **Historical rates**.

Gauge picks the most specific rate for an entry: a person's rate for that service, then the person's rate for all services, then the service rate for everyone, each the latest that took effect on or before the work date.
