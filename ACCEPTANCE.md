# Gauge acceptance record

Target edition: 17 October 2026. This keeps the existing row-based acceptance form and replaces the previous all-release verdict with per-clause `done`, `partial` or `missing` status, matching CONTRACT.md. Original baseline: `2d227a48623b4270f608fee6b9b672383093b379` (17 October 2026). Currency implementation update: 19 October 2026, tested by `tests/gauge-currency.mjs`. The original seventeen clauses retain their IDs, behavior and existing public-door test evidence. The operating core now saves agency currency and timezone, defaults new installations to USD and America/Los_Angeles, and retains historical currencies without conversion. Setup offers USD, AUD, CAD, EUR, GBP, NZD, CHF and SGD, all with two decimal minor units. Billing remains CSV packet preparation; no invoice issuance is claimed. The US target remains partial/missing where it has no corresponding implementation; no target journey below is asserted to have passed merely because it is written down.

Tests guard buyer journeys through built HTTP, browser, CLI, download and provider callback doors. Existing core checks: `tests/gauge.mjs`, `tests/gauge-currency.mjs`, `tests/gauge-agent.mjs`, `tests/gauge-forecast.mjs`, `tests/gauge-portability.mjs`; `tests/fresh-clone.mjs` covers the existing CLI/browser path at 1440 and 390. Network-edge sandboxes may stand in for paid providers. Target checks must use the actual application and verify the end state. Provider acceptance alone does not prove external completion.

## Upgrade and implementation limits

Applied migration history stays byte-for-byte unchanged. The currency implementation adds forward migration `0019_gauge_agency.sql`, which infers the agency currency from stored money without rewriting monetary records, revisions or approved artifacts. Empty installations default to USD; the owner saves the currency and IANA timezone at first-run setup. The existing local suites do not prove a real agency export, hosted capacity, a live provider integration or an actual billing period. A consenting agency must reconcile the whole source period and the first destination billing/collection cycle before retiring its incumbent (MIGRATE-010).

The canonical implementation status, evidence paths and remaining gaps are in CONTRACT.md, with one matching acceptance row here per clause. No test was weakened, renamed or removed to express the expanded target. Missing journeys are build obligations rather than application fallbacks.
